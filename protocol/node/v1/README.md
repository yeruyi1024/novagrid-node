# NodeChannel v1 Go 生成代码

本目录由 `novagrid-protocol` 的已发布 Tag `v0.1.0` 生成，源 Commit 为
`5455d11917ab684c84f164eaa7f12831f8fece6b`。生成文件不得手工修改。

生成器版本：

- `protoc 27.2`
- `protoc-gen-go v1.28.1`
- `protoc-gen-go-grpc v1.2.0`

在 NovaGrid 总工作区执行 `make generate-protocol` 可重新生成。脚本会先校验
Protocol Submodule 的准确 Commit，避免从漂移的 `main` 生成消费者代码。
